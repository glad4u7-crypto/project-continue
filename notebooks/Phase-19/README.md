# Phase 19 Notebook Archive

Store executed Phase 19 Jupyter notebooks here.

## Naming

Use descriptive, unique names, for example:

`ProjectContinue-Phase19-5-Acceptance-YYYYMMDD.ipynb`

Create a notebook only when the corresponding sub-phase/run is actually performed. Check for an existing file before creation. Never overwrite a prior notebook; use a new run/version suffix for reruns and link both artifacts in the phase report.

## Required evidence

Where applicable, retain notebook cells and outputs showing the checks performed, test summaries, errors, timestamp/timezone, repository commit, and relevant backup path. Redact all secrets.

A notebook's existence alone does not mean the sub-phase passed.
